# لِيبل «الشيخة ستايل GOLD» — نسخة محدّثة

إعادة تصميم لِيبل العبايات مع التعديلات المطلوبة:

- خط جديد كلاسيكي راقي لكلمة **GOLD** (٨ خيارات، الموصى به: كورمورانت مائل / سينزل)
- تصغير الاسم العربي «الشيخة ستايل» مع إمكانية التحكم بالحجم
- ذهب **معدني لامع** بتدرّج طبيعي بدل الجليتر الخشن
- **إطار لامع** بخط ذهبي متدرّج + خط داخلي رفيع (كلاسيكي مزدوج)
- الخلفية **أوف وايت** (`#FAF6EE`) بدل الأبيض الناصع

## الملفات الجاهزة للاستخدام — مجلد `final/`

| الملف | الاستخدام |
|---|---|
| `alsheikha-gold-offwhite-4800.png` | النسخة الأساسية (أوف وايت) — 4800×1920 |
| `alsheikha-gold-black-4800.png` | نسخة الخلفية السوداء |
| `alsheikha-gold-transparent-4800.png` | خلفية شفافة — للطبع على أي لون قماش أو ورق |
| `alsheikha-gold-cinzel-*.png` | نفس التصميم بخط GOLD البديل (سينزل) |
| `alsheikha-gold-*-vector.pdf` | ملف PDF بحجم ثابت للمطبعة (النص الذهبي داخله بدقة ≈ 5000 بكسل) |

## المعاينات — مجلد `previews/`

- `00-gold-fonts-sheet.png` — ورقة مقارنة تجمع خطوط GOLD الثمانية في صورة واحدة
- `01..08-*.png` — كل خط في صورة مستقلة
- `20..22-metal-*.png` — أنماط لمعة الذهب: معدني ناعم / لمعة قوية / ذهب عتيق
- `30-black.png`, `31-transparent.png` — نسخة سوداء ونسخة شفافة
- `40..45-ar-*.png` — بدائل خط الاسم العربي

## استوديو التعديل — `index.html`

صفحة واحدة تُفتح في المتصفح للتحكم المباشر: خط GOLD، لمعة الذهب، شكل الإطار، لون الخلفية،
حجم الاسم العربي وخطه، ولون `MADE IN QATAR` — مع أزرار تحميل PNG بدقة ×2 و×4 و×8.

**مهم:** الخط العربي في اللِيبل القديم كاليجرافي مرسوم يدوياً وغير متاح كملف خط، لذلك الخطوط
المعروضة هي أقرب البدائل. للحفاظ على شكل الاسم الحالي بالضبط: استخدم خيار
«ارفع الاسم العربي الأصلي» في الاستوديو وحدّد «احذف الخلفية البيضاء» — فيُركّب اسمك الأصلي
مع الإطار الجديد وكلمة GOLD الجديدة.

## إعادة توليد الصور (اختياري، لمن يعرف الأوامر)

```bash
npm i playwright-core
node render.mjs   # يولّد مجلد previews
node final.mjs    # يولّد مجلد final
```
