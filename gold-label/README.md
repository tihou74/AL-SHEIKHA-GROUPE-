# لِيبل «الشيخة ستايل GOLD» — نسخة محدّثة

إعادة تصميم لِيبل العبايات مع التعديلات المطلوبة:

- **قليتشر حقيقي** على كلمة GOLD بخمس درجات خشونة (الافتراضي: خشن)
- **١٦ خط** لكلمة GOLD كلها كلاسيكية راقية
- **٦ أشكال إطار** لامعة
- **١٠ خطوط** للاسم العربي + إمكانية استخدام خطك الأصلي من صورة
- الخلفية **أوف وايت** `#FAF6EE` بدل الأبيض الناصع

## الحفاظ على خط «الشيخة ستايل» الأصلي

الخط في اللِيبل القديم كاليجرافي مرسوم يدوياً وغير متاح كملف خط، ولا يمكن استخراجه من صورة معاينة.
لذلك يوفّر الاستوديو مساراً يحافظ عليه **بالضبط**:

1. ارفع صورة اسمك (أو صورة اللِيبل القديم كامله) من خيار «ارفع صورة اسمك».
2. اترك الخيار على «اطلِ خطي بالذهب الجديد» — يقرأ البرنامج شكل الحروف من الصورة
   (بمقارنة كل بكسل بلون خلفية الصورة، فيعمل مع الخلفية البيضاء والسوداء والشفافة)،
   ثم يعبّي الحروف بنفس ذهب GOLD وقليتشره.
3. يشذّب الهوامش تلقائياً، ويوجد شريطا «قص من أعلى / إلى» لعزل شريط الاسم من صورة اللِيبل الكامل،
   وشريط «حساسية» لضبط دقة استخراج الحروف.

النتيجة: خطك كما هو حرفياً، بذهب وإطار جديدين.

## استوديو التعديل — `index.html`

ملف واحد مستقل، **الخطوط ومكتبة التصدير مضمّنة داخله** (الخطوط مصغّرة على الحروف المستخدمة فقط
≈ ١٥٤ ك.ب) فيعمل بدون إنترنت. التحكم: خط GOLD، درجة القليتشر، أساس الذهب، شكل الإطار، الخلفية،
خط الاسم العربي وحجمه، رفع صورة الاسم، لون `MADE IN QATAR` — وأزرار تحميل PNG بدقة ×2 و×4 و×8.

## إعادة التوليد

```bash
npm i playwright-core
python3 build-fonts.py    # يبني الخطوط المضمّنة (fonts-embedded.css)
python3 inline-fonts.py   # يحدّثها داخل index.html
node render.mjs           # معاينات
node final.mjs            # ملفات جاهزة PNG/PDF
node verify-export.mjs    # يتحقق أن زر التحميل يعمل ومطابق
node test-upload.mjs      # يتحقق من مسار «صورة اسمك مطلية بالذهب»
```

### ما تم التحقق منه فعلياً

- توليد كل الصور والـPDF عبر Chromium مع فحص بصري (لا أخطاء JS في أي صفحة).
- **زر تحميل PNG**: جُرّب برمجياً من ملف محلي (`file://`) وأنتج 3200×1280 مطابقة للتصميم — بما فيها
  طبقة القليتشر (المبنية على `::before`) التي تُنقل بشكل صحيح إلى الصورة.
- **مسار صورة الاسم العربي**: جُرّب بصورة اختبار بخط مختلف وخلفية بيضاء؛ تم استخراج الحروف
  وتشذيب الهوامش وطلاؤها بالذهب، ونجح التصدير.
- الخلفية الشفافة: فحص بكسل — الزوايا وداخل الإطار شفافان فعلاً.
- الأوف وايت `#FAF6EE` مؤكد بفحص البكسل.
- إصلاح مثبت بالفحص: `border-image` بتدرّج لا يُصدَّر في PNG (كان يظهر مستطيلاً ذهبياً مصمتاً)،
  فاستُبدل بأربعة أشرطة متدرّجة مستقلة.

### ما لم يُتحقق منه

- الطباعة الفعلية على قماش/ستيكر (تحتاج تجربة مطبعة).
- سلوك زر التحميل على متصفحات غير Chromium (Safari/Firefox) — لم يُجرّب.
